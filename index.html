About

OARS 2026 explores the next generation of recommender systems: real-time, adaptive, and powered by LLMs and agentic workflows.

Static recommendation is no longer enough. This workshop focuses on real-time adaptation, LLM-powered systems, and real-world deployment challenges.

Key Themes

🤖 Agentic Systems

Tool use, memory, and assistant-style recommenders.

🧠 LLMs

Semantic IDs, multi-modal models, in-context learning.

⚡ Online Learning

Bandits, RL, and continual adaptation.

📊 Causal Methods

Evaluation, robustness, and counterfactuals.
